# Santosh Wake models

- `hey_santosh.onnx`: Santosh's own "Hey Santosh" classifier, trained by `wakeword/train.py` (Newtika).
- `melspectrogram.onnx`, `embedding_model.onnx`: feature models from the openWakeWord project
  (https://github.com/dscripka/openWakeWord), Apache License 2.0. The embedding model is derived from
  Google's speech_embedding model (Apache License 2.0).
