---
name: seo-page-audit
description: Audit a web page's SEO basics before publishing
---
GOAL: the page is findable and honest before it ships.

1. Title: one, <=60 chars, the real keyword present, no clickbait lie.
2. Meta description <=155 chars, says what the page actually delivers.
3. One H1; H2/H3 nest sensibly (no skipping levels); headings are headings,
   not bold text.
4. Images: every img has alt text; hero images compressed (<200 KB target).
5. Links: no dead links; external links on important sites carry rel where
   honest; internal links point at pages that exist.
6. Content: answers the question the searcher actually typed; first 100 words
   say the point; no keyword stuffing.
7. Technical: canonical correct, mobile viewport present, no blocked robots
   meta, sitemap entry added.
REPORT: pass/fail per point with the exact fix, then wait for her go.
