---
name: morning-briefing
description: Compose the morning briefing: weather, reminders, lists
---
GOAL: one short message that starts her day right.

1. Weather first (her city, today): condition, rain chance, one practical line
   (carry an umbrella / AC weather).
2. Reminders due today, in time order, each with its time. Cancelled ones
   never appear. Overdue from yesterday marked 'kal se pending'.
3. Open lists: only the UNticked items, top 3 per list, then '...aur 4 baaki'.
4. Her scheduled jobs that ran overnight: one line each, result only.
5. One line of memory worth remembering today (from the vault), if any.
6. Tone: Hinglish, warm, short. No bullet-point walls - 8 lines max.
7. Never invent: no forecast beyond what the weather service said, no reminder
   that is not in the data. A silent night says 'raat kuch nahi chala'.
