GOAL: campaign/marketing emails are ASSEMBLED from proven template structures (the
awesome-emails read), filled with HER facts - one shape from subject line to CTA,
and it reaches every mailbox.

THE LANE (existing doors only):
- Write with email_draft markdown=true - **bold**, *italic*, [links](url), bullets,
  headings. NEVER raw HTML (markdown is rendered, HTML is not).
- The same mail to a list -> email_bulk (mail merge; the approval card waits for
  the user's tap). Marketing publish -> kalam action=publish (card).
- Attachments: {drive_file_id} or file_id - no attachment unless the user asked.

THE TEMPLATE LIBRARY (structure + fill):
- OFFER/SALE: subject "Diwali sale - up to [X]% off at [shop name]" (<=45 chars);
  first line = preheader (inbox preview); 3 short lines with the heart of the
  offer; bullet list (3-5 items); ONE CTA link; last line the shop's name + city.
- NEWSLETTER: subject "This week: [topic]"; 3-4 sections, each section 2 lines +
  one link; consistent order (top update -> the rest -> one tip).
- APPOINTMENT/PAYMENT REMINDER: subject "Reminder: [item] [date]"; one line what,
  one line when, one line what to do (link or reply); warm tone, no blame.
- FESTIVAL GREETING: subject "Warm wishes for [festival]"; 2 heartfelt lines;
  one soft CTA (optional); greeting first, selling after.
- PRODUCT LAUNCH: subject "New [product] - [one benefit]"; problem (1 line) ->
  solution (2 lines) -> 3 bullets -> CTA; price only when the user gave it.
- FEEDBACK REQUEST: subject "2 minutes? Feedback on [work]"; why it matters
  (1 line); one link or one question; thanks.

THE LAWS:
- Only the user's facts: price, date, name, review - what they gave. Unknown =
  leave a [blank] and ask. Never an invented number/award/guarantee (kalam's law).
- Subject <=45 chars, first line = preheader, ONE CTA, paras 2-3 lines.
- Avoid the SPAM shape: ALL CAPS, !!!, "URGENT", fake "Re:" - no.
- A consent/unsubscribe line on bulk; only a list the user gave (never a
  bought/rented list).
NEVER: an OTP/password/card/Aadhaar number in a mail; a misleading subject; bulk
without the approval card; claim it was sent before the tool result.
