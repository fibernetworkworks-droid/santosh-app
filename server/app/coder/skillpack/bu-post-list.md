GOAL: a curated list like "Places to Post Your Startup" + the
awesome-billing catalog of billing tools = the syllabus. Every
founder asks before launch "where do I post?" - the list gives READY
targets, but Hoola runs it as a LEDGER, not as a spam queue. Each
target gets a card: name, its own rules, what is allowed, posted
date, link. Read the rules first, then post - that is what this
skill is for.

THE DOORS (all real operator tools):
1. memory_search / remember: every target's card lives here - name,
   its rules, what is allowed, posted date, link. If the card
   already exists do not fetch the rules again; a new target = a new
   card in remember. This is the ledger's full record.
2. hoola_find: find the target place's page and its RULES section.
   Many places ban self-promotion outright, many allow it only on a
   certain day, many ask for a founder-intro thread. No draft starts
   before the rules are read.
3. create_campaign: one target = one campaign. The posting lane runs
   on this - a draft per target, one place at a time.
4. control_campaign: pause / stop when a rule says otherwise or the
   founder says so; a campaign's state is changed only through this.
5. get_campaign_status: the answer to "is it posted?" comes only
   from here - printed status = evidence. The posted date / status
   on the card is updated from this.
6. consent_jaanch: BEFORE any step that touches an audience. To send
   anything straight to a group, a newsletter or members - consent
   first, then send.
7. email_bulk: only when the place allows email and consent is
   clear. Bulk = an audience, and an audience = only after consent.
8. list_lead_lists / get_lead_list: the founder's existing audience
   lists. Work from those lists; do not scrape something new to
   build an audience.

THE LAWS: rules FIRST, draft AFTER; one target = one card = one
posted-once record (a double post must show in the ledger);
consent_jaanch before any audience action, with no shortcut; any
step that costs money - paid boost, featured slot - ask_approval
ALWAYS; only printed output is evidence - status, link, date,
campaign id; never say "done" from memory or a guess; the founder's
private data never leaves the tenant - only what the founder asked
to share goes into a catalog.

NEVER: post on a place that bans promotion - if the rules are not
written down, ask, do not guess; double-post the same launch; buy a
paid boost without approval; lift a launch with fake upvotes or
shell accounts; say "it is posted" without printed status; run the
list as a copy-paste blast queue - one target at a time, one card
each.
