# Kenney models in Hoola's free library

The .glb files in this folder come from Kenney's own GitHub starter kits (github.com/KenneyNL: Starter-Kit-3D-Platformer,
Starter-Kit-City-Builder, Starter-Kit-FPS, Starter-Kit-Racing). Each kit's README states: "Assets included in this
package (2D sprites, 3D models and sound effects) are CC0 licensed" (https://creativecommons.org/publicdomain/zero/1.0/).
The kits' source code is MIT licensed, Copyright (c) 2023 Kenney; no kit code is used here.
Hoola changed one thing: each model's shared colour map picture is embedded inside its .glb so the file stands alone.
Do not use the Kenney logo alone to present these models.
